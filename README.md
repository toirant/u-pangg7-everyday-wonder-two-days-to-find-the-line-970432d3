## The entry

One sentence, at most 200 characters, on a small moment of wonder in everyday life:

> The lift doors opened on a stranger humming my grandmother's lullaby, and for one floor the building forgot what century it was.

## How it works

`main.ts` writes the entry sentence to `/output/entry.txt`. Run it with plain Node:

```sh
node main.ts
```

No dependencies, no flags, no network.
